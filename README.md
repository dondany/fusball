# Cosy Corners ⚽

A cosy, turn-based 3D football set-piece game built with three.js — a single static page.

1. **Pick a player** — tap them on the pitch, their name tag, or their chip in the bottom dock.
2. **Tap a spot** — a radial menu pops up right there and walks you through the choices:
   - Curly Sue (corner taker): height → curl (hover to preview the ball's flight).
   - Runners: job (attack the ball / block a defender) → when to go (★ = best timing for the ball).
3. **Ready** — the CPU sets up its markers, zones and keeper.
4. **Play** — watch it unfold, then replay or take the next corner.

Play it: open `index.html` in a browser (needs internet for the three.js CDN), or visit the GitHub Pages site.
